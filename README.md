# An Amazing Smile

Premium redesign for [An Amazing Smile](https://www.anamazingsmileaz.com/) — Tempe dental practice led by Dr. Zena Alshukri.

## Stack

- Vue 3 + TypeScript + Vite
- Tailwind CSS v4
- Vue Router
- GSAP (hero entrance only)
- Lucide icons (`@lucide/vue`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Photography is temporary (Unsplash). Replace with clinic assets in `src/data/images.ts` and `src/data/gallery.ts`.
- Contact form succeeds client-side for demo; wire to email/booking API before launch.
